C++ Fitness Tracker

A console-based fitness tracking application built using C++ as part of my Software Engineering coursework.

Features

Record workouts with names, durations, and calories burned

Organize exercises into Cardio, Strength, Flexibility, and Sports

Display workout history

Calculate total workout duration and calories burned

View workout summaries and exercise-type breakdowns

Technologies Used

C++

Object-Oriented Programming

STL Vectors

Smart Pointers (unique_ptr)

Classes, Structures, and Enumerations

How to Run

Compile using a C++17-compatible compiler:

clang++ -std=c++17 main.cpp FitnessTracker.cpp -o fitness-tracker

Run the program:

./fitness-tracker

What I Learned

This project helped me practice C++ programming, organizing code into multiple files, working with classes, and using vectors and smart pointers to manage workout data.
